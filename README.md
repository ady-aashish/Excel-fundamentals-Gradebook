Excel Gradebook – Coddy Excel Fundamentals

A practical Excel project completed as part of the Excel Fundamentals course on Coddy. This project demonstrates the use of spreadsheet basics, formulas, cell references, built-in functions, and logical operations to create a student gradebook.

📌 Overview

The Excel Gradebook is designed to organize student information, calculate academic totals and averages, and determine whether students pass or fail based on their performance.

This project applies the fundamental Excel concepts learned throughout the Coddy Excel Fundamentals course, bringing together data entry, formulas, functions, and logical operations in a practical spreadsheet.

🛠️ Skills Demonstrated

The project demonstrates the following Excel concepts and skills:

- Spreadsheet Organization: Working with cells, rows, columns, and structured tables.
- Data Entry: Entering and organizing text and numerical data.
- Formulas: Using arithmetic operators and mathematical expressions.
- Cell References: Referencing cells and ranges to create dynamic calculations.
- SUM Function: Calculating total marks.
- AVERAGE Function: Calculating average marks.
- IF Function: Applying logical conditions to determine pass or fail status.
- Basic Data Analysis: Summarizing and interpreting student performance.

Note: The skills listed above reflect the concepts covered in the course. The workbook's actual formulas and features determine which skills are demonstrated in the finished project.

📊 How to Use

1. Download the "gradebook.xlsx" file from this repository.
2. Open the workbook using Microsoft Excel or a compatible spreadsheet application.
3. Enter student information and marks in the appropriate cells.
4. Review the calculated totals and averages.
5. Check the pass/fail results generated using logical formulas.
6. Modify the input values to observe how the formulas update automatically.
